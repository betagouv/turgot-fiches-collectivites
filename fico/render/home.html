$logo Fiches collectivités BETA

Magasin de composants pour tableau de bord sur les collectivités territoriales, en PDF, en JSON ou en web components à intégrer dans une autre application.

Une fiche se demande par code INSEE de commune ou par SIREN de commune ou de groupement. Exemples : Rennes (PDF, JSON), Rennes Métropole, Ahaxe-Alciette-Bascassan.

Endpoints

GET /fiches/{identifiant}/{composant}.{format}les données brutes d'un composant en fichier : csv, xlsx ou geojson
GET /componentsla liste des composants, en JSON

Paramétrage

Les exemples portent sur Rennes.

  • Choisir les composants d'une fiche (HTML, PDF, JSON) : ?component=identite,financements.synthese. Sans ce paramètre, la fiche par défaut est rendue.
  • Paramétrer un composant : ses paramètres entre parenthèses, financements.historique(since=2020). Un même composant peut figurer plusieurs fois avec des paramètres différents : financements.carte(perimeter=departement),financements.carte(perimeter=interco).
  • Prendre une famille : financements.* désigne les composants de la fiche par défaut qui sont sous financements.
  • Composant seul : ses paramètres passent en query, /fiches/35238/financements.historique.html?since=2020.
  • Télécharger les données d'un composant, en valeurs brutes : les tableaux en .csv ou .xlsx, les cartes aussi, une ligne par commune, et en .geojson.
  • Paramètres disponibles : listés par /components, avec leur type, s'ils sont requis et leurs valeurs possibles, ainsi que les formats de téléchargement de chaque composant.
  • Détail des réponses : dans la documentation OpenAPI.

Intégrer un composant

Chaque composant est un web component qui charge lui-même son JSON. Pour l'intégrer dans une autre application :

  1. charger dans la page le CSS du DSFR, ses icônes « system » et fico.css : les composants n'apportent pas leurs styles ; 
    <link rel="stylesheet" href="$dsfr">
<link rel="stylesheet" href="$dsfr_icons">
<link rel="stylesheet" href="$base/assets/fico.css">
  2. importer component.js et placer un élément <fico-component> par composant, ses paramètres en attributs : 
    <script type="module" src="$base/assets/component.js"></script>
<fico-component name="identite" collectivite="35238"></fico-component>
<fico-component name="financements.historique" collectivite="35238" since="2020"></fico-component>

Pour une fiche entière, <fico-fiche> charge les composants choisis en un seul appel et les dispose comme le PDF : deux composants étroits qui se suivent partagent une ligne, un composant sans données disparaît. Avec les mêmes feuilles de style :

<script type="module" src="$base/assets/fiche.js"></script>
<fico-fiche collectivite="35238" components="identite,programmes,financements.historique(since=2020)"></fico-fiche>
