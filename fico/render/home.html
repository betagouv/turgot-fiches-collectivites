Fiches collectivités

Tableau de bord sur les dotations aux collectivités, en PDF, en JSON ou en web components à intégrer dans une autre application.

Une fiche se demande par code INSEE de commune ou par SIREN de commune ou de groupement. Exemples : Rennes (PDF, JSON), Rennes Métropole, Ahaxe-Alciette-Bascassan.

Endpoints

EndpointRôle
GET /fiches/{identifiant}.htmlla fiche en page web
GET /fiches/{identifiant}.pdfla fiche en PDF
GET /fiches/{identifiant}.jsonles données de tous les composants
GET /fiches/{identifiant}/{composant}.jsonles données d'un composant
GET /fiches/{identifiant}/{composant}.htmlun composant seul, en page web
GET /componentsla liste des composants, en JSON

Paramétrage

  • Choisir les composants d'une fiche (HTML, PDF, JSON) : ?component=identite,historique. Sans ce paramètre, la fiche par défaut est rendue.
  • Paramétrer un composant : ses paramètres entre parenthèses, historique(since=2020). Un même composant peut figurer plusieurs fois avec des paramètres différents.
  • Prendre une famille : carto.* désigne les composants de la fiche par défaut qui sont sous carto.
  • Composant seul : ses paramètres passent en query, /fiches/35238/historique.json?since=2020.
  • Paramètres disponibles : listés par /components, avec leur type, s'ils sont requis et leurs valeurs possibles.
  • Détail des réponses : dans la documentation OpenAPI.

Intégrer un composant

Chaque composant est un web component qui charge lui-même son JSON. Pour l'intégrer dans une autre application :

  1. charger dans la page le CSS du DSFR et fico.css : les composants n'apportent pas leurs styles ;
  2. importer component.js et placer un élément <fico-component> par composant, ses paramètres en attributs, comme ci-dessous.
<link rel="stylesheet" href="https://fico.example/assets/fico.css">
<script type="module" src="https://fico.example/assets/component.js"></script>
<fico-component name="identite" collectivite="35238"></fico-component>
<fico-component name="historique" collectivite="35238" since="2020"></fico-component>

Pour une fiche entière, <fico-fiche> charge les composants choisis en un seul appel et les dispose comme le PDF : deux composants étroits qui se suivent partagent une ligne, un composant sans données disparaît.

<script type="module" src="https://fico.example/assets/fiche.js"></script>
<fico-fiche collectivite="35238" components="identite,programmes,historique(since=2020)"></fico-fiche>
